Questions fréquentes

Comment envoyer de l'argent ?

Pour envoyer de l'argent, rendez-vous dans la section "Envoyer de l'argent" depuis votre tableau de bord. Sélectionnez votre opérateur, entrez le montant, ajoutez les informations du destinataire, puis validez. Le destinataire recevra les fonds instantanément sur son compte mobile money.

Comment ajouter un bénéficiaire ?

Dans la rubrique "Bénéficiaires", cliquez sur "Ajouter". Renseignez le nom, le numéro de téléphone et le pays. Vous pouvez aussi importer vos contacts depuis votre téléphone ou scanner un QR code TransAfrik.

Comment déposer de l'argent ?

Allez dans la section "Dépôt". Sélectionnez votre pays et opérateur, entrez le montant à déposer, puis validez le paiement via votre mobile money. Une fois le paiement confirmé, votre portefeuille TransAfrik sera crédité automatiquement.

Pourquoi mon transfert est en attente ?

Un transfert peut être en attente pour plusieurs raisons : vérification de sécurité, problème de réseau mobile money, ou validation en cours. Si votre transfert reste bloqué plus de 10 minutes, contactez notre support. Les statuts sont visibles dans votre historique.

Comment récupérer mon compte ?

Si vous avez perdu l'accès à votre compte, utilisez la fonction "Mot de passe oublié" sur la page de connexion. Un code de vérification vous sera envoyé par SMS. Si vous ne recevez pas le SMS, contactez notre support avec une preuve d'identité.

Comment modifier mon numéro ?

Allez dans "Paramètres" > "Changer de numéro". Saisissez votre nouveau numéro et confirmez. Un code de vérification sera envoyé sur votre nouveau numéro pour valider la modification.

Comment fonctionne la vérification KYC ?

La vérification KYC (Know Your Customer) est obligatoire pour débloquer toutes les fonctionnalités. Rendez-vous dans "Vérification KYC", remplissez vos informations personnelles, téléchargez une pièce d'identité valide (recto/verso) et un selfie. Notre équipe vérifie votre dossier sous 24-48h.

Comment contacter un conseiller ?

Utilisez le chat en direct ci-dessous pour parler à un conseiller. Vous pouvez aussi créer un ticket ou nous contacter par email à support@transafrik.com. Le support est disponible 24h/24, 7j/7.

Comment supprimer mon compte ?

Allez dans "Paramètres" > "Sécurité" > "Supprimer mon compte". Vous devrez confirmer avec votre mot de passe. La suppression est réversible pendant 30 jours. Passé ce délai, toutes vos données seront définitivement effacées.

Comment modifier mon mot de passe ?

Dans "Paramètres" > "Changer le mot de passe", saisissez votre mot de passe actuel, puis le nouveau. Choisissez un mot de passe robuste d'au moins 8 caractères avec lettres, chiffres et caractères spéciaux.

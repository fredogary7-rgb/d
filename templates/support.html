Support en ligne

Rendez-vous dans « Envoyer de l'argent », choisissez le pays et l'opérateur du destinataire, saisissez le montant et les informations du bénéficiaire, puis validez. Les fonds arrivent instantanément sur son compte mobile money.

Dans « Mes bénéficiaires », cliquez sur « Ajouter ». Renseignez le nom, le numéro et le pays. Vous pouvez aussi importer un contact ou scanner un QR code TransAfrik.

Un transfert peut être en attente à cause d'une vérification de sécurité, d'un problème réseau mobile money ou d'une validation en cours. S'il reste bloqué plus de 10 minutes, contactez le support.

Les frais sont calculés automatiquement avant validation. Ils dépendent du montant, du pays et de l'opérateur. Le montant total (montant + frais) est toujours affiché avant de confirmer.

Allez dans « Dépôt », sélectionnez votre pays et opérateur, entrez le montant, puis validez le paiement mobile money. Votre portefeuille TransAfrik est crédité automatiquement après confirmation.

Dans « Retrait », choisissez le pays et l'opérateur de destination, saisissez le numéro du destinataire et le montant, puis confirmez. Le retrait est traité et crédité sur le compte mobile money.

La vérification KYC est obligatoire pour débloquer toutes les fonctionnalités. Renseignez vos informations, téléversez une pièce d'identité valide et un selfie. Notre équipe valide le dossier sous 24–48h.

Utilisez « Mot de passe oublié » sur la page de connexion. Un code de vérification vous sera envoyé. Si vous ne le recevez pas, contactez le support avec une preuve d'identité.

Dans « Paramètres » → « Changer le mot de passe », saisissez l'ancien puis le nouveau. Choisissez un mot de passe robuste d'au moins 8 caractères.

Dans « Paramètres » → « Changer de numéro », saisissez votre nouveau numéro. Un code de vérification est envoyé pour valider la modification.

Dans « Paramètres » → « Sécurité » → « Supprimer mon compte », confirmez avec votre mot de passe. La suppression est réversible pendant 30 jours.

Ouvrez un ticket dans l'onglet « Mes tickets » ou écrivez-nous à support@transafrik.com. Le support est disponible 24h/24, 7j/7.
